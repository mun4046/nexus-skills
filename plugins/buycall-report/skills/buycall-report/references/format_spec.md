# 보고서 포맷 스펙

## 레이아웃 (3~4페이지, A4)
- **1페이지 — sell-side 원페이저**: 상단 로고+날짜 / 좌측 데이터 사이드바(투자의견 박스·Stock Data·상대수익률·주가차트 자리·작성자) / 우측 본문(종목명+코드 → 한 줄 헤드라인 → ▌매매전략 표 → ▌핵심결론 → ▌투자포인트①②③) / 하단 전체폭 Forecasts & Valuations 표.
- **2페이지**: `1 기업 개요` 표 + 사업 한 줄 요약 / `2 매수 이유` ①~④ / `3 밸류에이션` 서술 + 동종업계 비교(Peers) 표 + 목표가 산정 표.
- **3페이지**: `4 매매 전략 상세` 표(매수가·손절가·목표가·전략유형) + 진입/청산 서술 / `5 리스크 요인 및 재검토 조건` / `6 결론` / 부록 요약 재무제표.

## 디자인 토큰
- 폰트 `맑은 고딕`. 컬러: 브랜드골드 `#9D844E`(강조선·키수치), 진한골드 `#7A663C`(표 헤더 fill+흰 글씨), 연골드 `#F1EBDD`(매매전략 라벨), 따뜻한 연회색 `#F5F2EA`(alt row), 본문 `#333333`, 보더 `#C9BFA8`.
- 회사가 다르면 `scripts/gen_report.py` 상단 컬러 상수와 `assets/` 로고만 교체.

## 규칙
- **파일명**: `종목명_매매전략_YYMMDD.docx` (일자=작성일).
- **어투**: 개조식(~함/~임/~했음). 면책 조항 없음.
- **as-of 작성**: 작성일 = 최초 매수일 기준 — 추세추종·단기 트레이딩은 돌파 확인 1영업일 전, 가치투자는 2영업일 전. 작성일 시점에 알 수 있는 정보만 사용하고 **미래 정보(매도 결과 등)는 본문에 절대 노출하지 않음**.
- **내러티브 우선**: 재무지표 나열을 지양하고 거래의 전략 유형(추세추종/테마 모멘텀/단기 트레이딩/가치투자)에 맞는 논리·맥락을 서술.
- **페이지 맞춤**: 1페이지에 요약표까지 들어가려면 핵심결론 ~3줄, Forecasts 표 ~6행 유지(우측 본문이 길면 표 마지막 줄이 다음 장으로 밀림). 페이지 나눔은 `add_page_break()` 대신 다음 제목의 `page_break_before=True` 사용(빈 페이지 방지).
- **Peer 표**: 실데이터 사용. 실적 저점·적자 종목은 PER이 왜곡되므로 평균은 정상치 기준/적자 제외, PBR·ROE 병행, 각주(`peer_note`)로 한계 명시. ROE ≈ PBR/PER×100 으로 산출 가능.

## build(D) dict 스키마
```python
D = dict(
  fname='종목명_매매전략_YYMMDD.docx', date='YYYY.MM.DD',
  name='종목명', code='000000', sector='시장 · 섹터',
  headline='한 줄 투자 논지 헤드라인',
  opinion='BUY (전략유형)', tp='000원', cp='000원', upside='+0.0%',
  stock=[('시가총액','...'),('발행주식수','...'),('52주 최고','...'),('52주 최저','...'),
         ('외국인지분','...'),('60일 거래대금','...'),('PER(12M Fwd)','...'),('PBR','...')],  # 8행
  rel=['+1M','+3M','+6M','+12M'],            # KOSPI(KODEX200) 대비 초과수익 %p
  stype='추세추종(돌파)', period='1 ~ 3개월', band='000 ~ 000원',
  stop='000원 (-0%)', t1='000원 (+0%)', t2='000원 (+0%)',
  call='핵심결론 3~4문장 (개조식)',
  points1=['투자포인트1','투자포인트2','투자포인트3'],   # 1페이지용 짧은 문구 3개
  fin_years=['2023','2024','2025','2026E'],            # 4~5개
  fin=[('매출액',...),('영업이익',...),('순이익',...),('EPS(원)',...),('ROE(%)',...),('PBR(배)',...)],  # 6행 권장
  snapshot=[('사업 영역','...','주요 고객/테마','...'),('시가총액','...','발행주식수','...'),('52주 최고/최저','...','외국인 지분','...')],
  biz='사업 한 줄 요약',
  thesis=[('① 제목 — ','내용(개조식)'),('② ...','...'),('③ ...','...'),('④ ...','...')],  # 3~4개
  val_text='밸류에이션 서술',
  peers=[['Peer1','PER','PBR','ROE'],['Peer2',...],['Peer3',...],['(평균)',...],['대상종목(현재)',...]],  # 선택
  peer_note='Peer 표 각주(선택)',
  tpcalc=[('적용이익\n(기준)',False),('멀티플',False),('목표주가',True),('현재주가',False),('상승여력',True)],
  val_note='목표가 산정 근거(개조식)',
  ts_row=['매수가','손절가','목표가','전략유형'],   # 각 셀 줄바꿈(\n) 허용
  ts_text='진입/청산/비중 규칙(개조식)',
  risks=['리스크1','리스크2','리스크3'],
  review='재검토(매도) 조건 ①②③',
  concl='결론(개조식)',
  appx_years=['2024','2025'],
  appx=[('자산총계',...),('부채총계',...),('자본총계',...),('부채비율(%)',...),('ROE(%)',...)],
  reporter=['Reported by','홍길동  (PM / Buy-side)','hong@firm.co.kr'],  # 선택
)
```
JSON 입력 시 튜플은 배열로 표기(`tpcalc` 의 bool 은 true/false). `gen_report.py` 가 자동 정규화.
